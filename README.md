# artyrkalauch

Быстрый и удобный лаунчер Minecraft. Fabric из коробки, менеджер модов,
несколько аккаунтов, автоустановка Java. Без .NET, без рекламы.

## скачать

последняя версия → [Releases](https://github.com/artyrka31/artyrkalauch/releases/latest)

## возможности

- Vanilla + Fabric любой версии
- Менеджер модов (drag & drop, включение/выключение, скачивание по URL)
- Несколько аккаунтов — offline и Microsoft
- Автоустановка Java (если её нет)
- Настройки: память, полноэкранный, аргументы Java и Minecraft
- Сохранение настроек в `%APPDATA%\artyrkalauch\`

## система

- Windows 10/11 x64
- .NET не требуется (self-contained)
